# User Interface (UI)

The UI is primarily how we interact with the back-end server. **With the server running**, the UI can be interacted with through a web browser at `http://localhost:8091/app/`.


## Creating a new user
Create a Tubely account by entering an email and password and clicking "sign up".


## Creating a video draft
Create a video draft by entering the "Video title" and "Video description" and clicking "Create draft". This will add the draft to the "All Videos" list. The "Current Video" shows the options to "Update Thumbnail" and "Update Video File".
